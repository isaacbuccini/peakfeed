PeakFeed

A personal tool for turning your own long videos into short vertical clips, and publishing the ones you approve to your own accounts.

Last updated 11 November 2026

What it is

PeakFeed is a personal software project written and run by one individual developer. It is not a hosted service. There is no website to sign up for, no account to create here, and no server that holds anyone's data. The software runs on the developer's own computer and works only with that person's own accounts.

This page exists because platform developer portals require an application to publish a homepage, terms of service and privacy policy before granting API access. Those documents are below, and they describe what the software genuinely does.

What it does

  • Reads a long video the operator already has, or one they are authorised to use.
  • Transcribes it locally and suggests shorter segments that might work as clips.
  • Reframes those segments to vertical 9:16, adds subtitles, and renders them.
  • Shows each clip for review. Nothing is published without a human approving it first.
  • Uploads approved clips to the operator's own connected accounts.

Platform connections

The operator may connect their own accounts on third-party platforms using each platform's official OAuth flow. PeakFeed never asks for, sees, or stores a platform password — authentication happens on the platform's own sign-in page, and the platform returns a token.

On TikTok, uploaded clips are sent to the account holder's own inbox as drafts. The account holder then opens TikTok and decides whether to post them. PeakFeed does not post publicly on anyone's behalf.
